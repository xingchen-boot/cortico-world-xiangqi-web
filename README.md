# cortico-world-xiangqi-web

Coopanion / Cortico 扩展。在 [chess.z3web.cn](https://chess.z3web.cn/game/single/) 上和电脑下中国象棋。棋步在网页里算，不把棋盘送进聊天。

需要本机已安装的 Edge 或 Chrome。

## 配置

| 键 | 说明 |
| --- | --- |
| `worlds.xiangqi-web.enabled` | 是否启用 |
| `worlds.xiangqi-web.level` | 网站上的难度，默认「中级」 |
| `worlds.xiangqi-web.ownerQq` | 这位的 QQ 号。下棋时他发来消息就停手。空着就只认桌宠上的话 |
| `worlds.xiangqi-web.lessonsFile` | 记下的教训。空着就放在数据目录的 `xiangqi-lessons.txt` |
| `worlds.xiangqi-web.browserPath` | 浏览器路径。空着就在常见安装位置找 |
